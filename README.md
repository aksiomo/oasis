# OaSis

由 Aksiomo 与 CR 合作开发的开源流程自动化软件。

前端使用 Vite + React + React-Router 开发，后端使用 Go + Gin，持久层使用 PostgreSQL，缓存使用 Redis，消息队列使用 RabbitMQ。

## 项目代码结构与分支管理

### 代码结构

client：项目前端

server：项目后端

### 分支管理

- main：主分支
- dev：开发分支
- git-page：纯前端展示
