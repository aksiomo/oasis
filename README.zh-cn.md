# OASis

> 这个页面 100% 是由人编写的

其他语言版本：[English](./README.md) | [Esperanto](./README.eo.md)

这是一个由 [Aksiomo](https://github.com/aksiomo) 和 [CR](https://github.com/Churong-Leung) 共同完成的办公自动化系统。  
前端使用了 `Vite` 和 `React` 以及 `Tanstack-Router`。  
后端使用了 `Go` 和 `Gin` 以及 `GORM`。  

## 关于这个项目

### 基础结构

```plaintext
|- client # 前端
|- server # 后端
|- ...
```

### 分支

```plaintext
|- main # 主分支
|- dev # 开发分支
|- (staging) # 测试分支，也许以后会加入
```

### 项目成员

|任务|负责人|
|---|---|
|产品, 需求, UI, 测试|[CR](https://github.com/Churong-Leung)|
|架构, 开发, 实施|[Aksiomo](https://github.com/aksiomo)|
