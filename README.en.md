# OaSis

Open-source process automation software co-developed by Aksiomo and CR.

The frontend is built with Vite + React + React-Router, the backend with Go + Gin, PostgreSQL for persistence, Redis for caching, and RabbitMQ for the message queue.

## Project Structure and Branch Management

### Code Structure

client: frontend
server: backend

### Branch Management

- main: main branch
- dev: development branch
- git-page: frontend-only showcase

## Development Roles

Product, requirements, UI, testing: CR
Architecture, development, implementation: Aksiomo
